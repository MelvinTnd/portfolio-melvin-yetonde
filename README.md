# Portfolio - Melvin Yetonde

Portfolio et centre d'organisation de mes projets de développement full stack / backend / IA / e-commerce.

## Vue d'ensemble

Je conçois et développe des applications web complètes, des APIs, des outils SaaS, et des démonstrateurs d'IA en mettant l'accent sur la qualité produit, l'architecture, la maintenabilité et le déploiement.

## Stack principale

- Frontend : Next.js, React, TypeScript, Tailwind CSS, HTML/CSS/JS
- Backend : Laravel, PHP, Sanctum, API REST
- Data : PostgreSQL, Redis
- IA / média : Replicate, FFmpeg, pipelines de traitement
- DevOps : Docker, Vercel, GitHub Actions

---

## Workflow de développement

1. Concevoir le produit et l'architecture
2. Développer les MVP ou prototypes fonctionnels
3. Séparer front-end, API et services métier
4. Mettre en place les tests et validations métier
5. Déployer et mesurer les performances

## À retenir pour un nouveau développeur

- Les projets sont structurés par cas d'usage et non seulement par technologie.
- Les repos sont conçus pour être lisibles séparément, mais restent connectés à une logique globale de portfolio.
- Les projets les plus importants sont les applications produit et les backends associés.
